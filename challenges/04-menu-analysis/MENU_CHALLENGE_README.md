# 춘식도락 메뉴판 분석 챌린지

## 프로젝트 개요
카카오 구내식당 **춘식도락**의 2025년 1-2월 메뉴판 이미지를 분석하여 5가지 문제를 해결하는 챌린지입니다.

## 데이터
- **위치**: `menu_images/` 폴더
- **파일**: 8개 PNG 이미지 (주간 메뉴판)
- **분석 기간**: 2025년 1-2월만 사용 (7개 이미지)

## 문제 목록

### 문제 1: 조리법별 메뉴 분석 (10점)
1월 13일 주간(1/13-1/17) 중식의 한식A, 한식B, 팝업A, 팝업B, 양식 코너에서 제공된 반찬들을 분석했을 때, 반찬명이 정확히 **조림, 볶음, 무침, 구이**로 끝나는 개수를 내림차순으로 정렬하세요.

**예시**:
- 두부조림 → 조림 (O)
- 상추양배추쌈*쌈장 → 해당 없음 (X)

**답안 형식**: `볶음 > 무침 > 조림 > 구이`

---

### 문제 2: 1월 칼로리 순위 분석 (15점)
1월 전체 중식의 한식A, 한식B, 양식, 팝업A, 팝업B 코너의 **평균 칼로리**를 각각 계산하고 내림차순으로 정렬하세요.

**답안 형식**: `양식 > 한식A > 팝업B > 한식B > 팝업A`

---

### 문제 3: 지역 특색 메뉴 (15점)
1, 2월의 모든 범위(중식, 중식 TAKE OUT, 석식, 석식 TAKE OUT)의 **메뉴명**에 포함된 지역명(국가/도시/지명)을 추출하고, **2회 이상 등장한 지역**을 모두 선택하세요.

**선택지**: 안동, 전주, 베트남, 나가사키, 태국

**답안 형식**: 복수 선택 (체크박스)

---

### 문제 4: 메뉴별 칼로리 비교 (10점)
1, 2월에서 다음 메뉴들의 칼로리를 찾아 내림차순으로 정렬하세요.

**대상 메뉴** (가나다순):
- 덴가스떡볶이
- 돈코츠라멘
- 마라탕면
- 수제남산왕돈까스
- 탄탄면

**답안 형식**: `수제남산왕돈까스 > 돈코츠라멘 > 마라탕면 > 탄탄면 > 덴가스떡볶이`

---

### 문제 5: 2월 한 달 식단 최적화 챌린지 (40점)
2월 한 달간 칼로리 기준으로 최적 조합을 찾아보세요.

**분석 대상 코너**:
- 중식: 한식A, 한식B, 양식, 팝업A, 팝업B
- 중식 TAKE OUT: 샐러드, 비건, 라이스&누들, 버거&델리
- 석식: 한식B, 샐러드바
- 석식 TAKE OUT: 샐러드, 버거&델리

**조건**:
1. **월-목요일**: 같은 날짜에 중식과 석식의 합계 칼로리가 **1,550kcal에 가장 근접**한 코너 조합을 찾으세요.
2. **금요일**: 가장 칼로리가 낮은 중식 코너를 찾아주세요.

**답안 형식**:
```json
[
  {"id": "2025-02-03", "lunch": "샐러드", "dinner": "한식B"},
  {"id": "2025-02-04", "lunch": "팝업B", "dinner": "샐러드"},
  ...
  {"id": "2025-02-28", "lunch": "샐러드"}
]
```

**배점**: 날짜당 2점, 총 20일

## 사용 방법

### 방법 1: Streamlit 웹 앱 (추천)

```bash
streamlit run menu_data_entry.py
```

**기능**:
1. **데이터 입력 탭**: 메뉴판 이미지를 보면서 수동으로 데이터 입력
2. **문제 풀이 탭**: 각 문제별 자동 분석 및 답안 생성
3. **데이터 관리 탭**: JSON 저장/불러오기
4. **도움말 탭**: 사용 가이드

### 방법 2: Python 스크립트

```bash
python menu_analysis.py
```

OCR 기반 자동 분석 (Tesseract 설치 필요)

## 주의사항

1. **날짜 범위**: 2025년 1-2월 데이터만 분석 (2024-12-30.png 제외)
2. **정확성**: 메뉴판에 기재된 메뉴명과 텍스트가 분석의 기준
3. **반찬 조리법**: 정확히 "조림", "볶음", "무침", "구이"로 **끝나는** 것만 카운트
4. **TAKE OUT 표기**: 문제 5에서는 "TAKE OUT"이 아닌 세부 코너명(샐러드, 비건 등)으로 기재

## 빠른 시작

### 1. Streamlit 앱 실행
```bash
streamlit run menu_data_entry.py
```

### 2. 메뉴 데이터 입력
- [menu_images/2025-01-06.png](menu_images/2025-01-06.png) 이미지를 열어 봅니다
- 웹 앱의 "데이터 입력" 탭에서 각 메뉴 정보를 입력합니다
- 날짜, 식사 구분, 코너, 메뉴명, 칼로리, 반찬을 차례로 입력
- "메뉴 추가" 버튼 클릭

### 3. 문제 풀이
- "문제 풀이" 탭으로 이동
- 각 문제의 "풀이" 버튼 클릭
- 자동으로 계산된 답안 확인

### 4. 데이터 저장
- "데이터 관리" 탭에서 "JSON 저장" 버튼 클릭
- 다음 작업 시 저장된 파일 불러오기 가능

## 팁

### 시간 관리
- **0-30분**: 데이터 입력 시스템 구축 또는 OCR 설정
- **30-90분**: 메뉴 데이터 입력 (수동) 또는 OCR 실행
- **90-110분**: 문제 풀이 로직 구현 및 검증
- **110-120분**: 최종 답안 정리 및 제출

### 효율적인 데이터 입력
1. 한 주(5일치)씩 묶어서 입력
2. 코너별로 정렬하여 입력
3. 중간중간 JSON으로 저장하여 백업
4. 칼로리와 반찬명 정확히 확인

### 검증
- 문제 5의 경우 총 20일치 데이터 필요 (2월 평일 기준)
- 금요일은 석식이 없으므로 중식만 입력
- 1550kcal 근접 여부를 계산 결과에서 확인
