# Age of AI Challenge - Critical Issues

## ⚠️ URGENT: Multiple Choice Questions

### Question 5 (10점) - 복수 선택
**현재 상태**: 1개만 선택됨
- ✓ 미국 아리조나 TuSimple 본사

**문제**:
- 문항이 "영상에 등장하는 지역을 **모두** 선택하세요"
- 복수 선택 문항은 **부분 점수 없음**
- 모든 정답을 선택해야 점수 획득

**가능한 다른 지역들**:
- 한국 인천국제공항
- 미국 캘리포니아 롱비치공항
- 한국 동서울 톨게이트
- 캐나다 워털루 대학교

**해결 방법**:
영상 "로봇이 내 일자리를 빼앗을까?"를 시청하고 등장하는 모든 지역 확인 필요

### Question 7 (15점) - 복수 선택
**현재 상태**: 3개 선택됨
- ✓ 팀쇼를 위한 연구는 음성 인식과 음성 합성을 포괄한다
- ✓ 망막병증 프로젝트에서는 100,000건의 질병에 걸린 안구사진을 통해 학습을 진행했다
- ✓ 인공지능 눈 스캐너는 인도의 시골지역에서 시험했다

**미선택 항목**:
- ✗ NFL 시즌 시작 인터뷰에서 팀쇼의 등번호는 8번이다
- ✗ 아이스버킷 챌린지는 음성인식 연구에 도움이 되었다

**문제**:
- 복수 선택 문항은 **부분 점수 없음**
- 5개 중 3개만 선택 - 정답이 3개인지, 더 있는지 확인 필요
- 잘못 선택하면 15점 전부 잃음

**해결 방법**:
영상 "AI를 통한 치유"를 시청하고:
1. 팀쇼의 등번호 확인 (NFL 시즌 인터뷰 장면)
2. 아이스버킷 챌린지 언급 여부 확인
3. 이미 선택한 3개 항목도 재확인

## 다른 답안 확인 필요 항목

### Question 1 - 음료 종류
- **선택**: 카푸치노
- **확인**: 영상에서 킹콩/아바타 작업자가 마시는 음료를 육안으로 확인
- **힌트**: 잔의 모양, 색상, 거품 여부 등

### Question 2 - 첫 테스트 문장
- **입력**: "I love you"
- **확인**: 영상 자막/음성에서 첫 번째로 시험한 문장 확인
- **주의**: "처음 사용된 문장"이므로 시간 순서 중요

### Question 3 - 피트스톱 시간
- **입력**: 12.12초
- **확인**: 화면에 표시된 타이머 정확히 읽기
- **주의**: 소수점 이하 자리수 정확히

### Question 4 - Bobo 배우 직업
- **선택**: 뮤지션
- **확인**: 영상에서 배우 소개 부분 확인
- **힌트**: 인터뷰나 내레이션에서 언급

### Question 6 - 마커 개수
- **입력**: 7개
- **확인**: 화면의 마커를 하나씩 세기
- **세부**:
  - 콧등: ?개
  - 양쪽 눈: ?개
  - 눈썹: ?개
  - 합계: 7개
