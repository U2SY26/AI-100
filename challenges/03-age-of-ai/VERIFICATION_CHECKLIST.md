**질문**: 영상에 등장하는 지역을 **모두** 선택하세요

#### 현재 선택된 답
- [x] 미국 아리조나 TuSimple 본사

#### 확인해야 할 항목들
영상을 보면서 다음 장소들이 **화면에 표시되거나 언급되는지** 확인:

- [ ] **한국 인천국제공항**
  - 공항 표지판, 한글 간판 확인
  - "Incheon Airport" 텍스트 확인

- [ ] **미국 캘리포니아 롱비치공항**
  - "Long Beach Airport" 표시 확인
  - 캘리포니아 지역 언급 확인

- [ ] **한국 동서울 톨게이트**
  - 톨게이트 장면 확인
  - "동서울" 표시 확인

- [ ] **캐나다 워털루 대학교**
  - "University of Waterloo" 표시 확인

#### 검증 방법
1. 영상 전체를 시청하며 지명/장소 표시 주목
2. 자막에서 지명 언급 확인
3. 화면 하단/모서리의 위치 정보 확인
4. 인터뷰 장소 소개 부분 확인

#### 예상 등장 장면
- 자율주행 트럭 관련: TuSimple (확인됨), 공항/톨게이트 가능성
- 연구소/대학 방문: 워털루 대학교 가능성
- 국제 비교: 한국 장면 가능성

### Question 7 (15점) - AI를 통한 치유
**영상**: https://www.youtube.com/watch?v=V5aZjsWM2wo

**질문**: 영상에서 확인할 수 있는 사실을 **모두** 선택하세요

#### 현재 선택된 답 (3개)
- [x] 팀쇼를 위한 연구는 음성 인식과 음성 합성을 포괄한다
- [x] 망막병증 프로젝트에서는 100,000건의 질병에 걸린 안구사진을 통해 학습을 진행했다
- [x] 인공지능 눈 스캐너는 인도의 시골지역에서 시험했다

#### 확인해야 할 항목들

**1. NFL 시즌 시작 인터뷰에서 팀쇼의 등번호는 8번이다**
- [ ] NFL 인터뷰 장면 찾기
- [ ] 팀쇼의 유니폼 번호 확인
- [ ] 등번호가 8번인지 다른 번호인지 확인
- **확인 지점**: 인터뷰 장면, 유니폼 클로즈업

**2. 아이스버킷 챌린지는 음성인식 연구에 도움이 되었다**
- [ ] 아이스버킷 챌린지 언급 여부
- [ ] ALS 관련 내용 확인
- [ ] 음성인식 연구와의 연결 언급
- **확인 지점**: 팀쇼 이야기 부분, ALS 설명 부분

**3. 팀쇼를 위한 연구는 음성 인식과 음성 합성을 포괄한다** ✓
- [ ] 음성 인식(speech recognition) 언급 재확인
- [ ] 음성 합성(speech synthesis) 언급 재확인
- **확인 지점**: 연구 소개 부분

**4. 망막병증 프로젝트에서는 100,000건의 질병에 걸린 안구사진을 통해 학습을 진행했다** ✓
- [ ] 망막병증(diabetic retinopathy) 프로젝트 확인
- [ ] 데이터 건수가 100,000건인지 확인
- [ ] "질병에 걸린 안구사진" 표현이 맞는지 확인
- **확인 지점**: 안과 AI 프로젝트 부분

**5. 인공지능 눈 스캐너는 인도의 시골지역에서 시험했다** ✓
- [ ] 인도(India) 장면 확인
- [ ] 시골지역(rural area) 언급 확인
- [ ] 눈 스캐너 테스트 장면
- **확인 지점**: 인도 현장 테스트 부분

#### 검증 방법
1. 영상 전체를 시청하며 각 사실 언급 부분 찾기
2. 숫자 정보는 화면/자막에서 정확히 확인
3. 이미 선택한 3개 항목도 재확인
4. 거짓 선택지 주의 (비슷하지만 다른 내용)
