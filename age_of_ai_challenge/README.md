## 우선순위 확인 항목

### 🔴 HIGH (25점 위험)

1. **Question 7** (15점) - "AI를 통한 치유"
   - 현재: 3개 선택됨
   - 확인 필요:
     - [ ] 팀쇼 등번호가 8번인가?
     - [ ] 아이스버킷 챌린지가 언급되는가?
     - [ ] 3개 선택 항목 재확인

2. **Question 5** (10점) - "로봇이 내 일자리를 빼앗을까?"
   - 현재: 1개만 선택 (미국 아리조나 TuSimple)
   - 확인 필요:
     - [ ] 인천국제공항 등장?
     - [ ] 롱비치공항 등장?
     - [ ] 동서울 톨게이트 등장?
     - [ ] 워털루 대학교 등장?

### 🟡 MEDIUM (15점)

3. **Question 6** (15점) - "사랑, 예술 그리고 이야기를 이해하다"
   - 답: 7개 마커
   - 확인: 화면에서 콧등 + 양쪽 눈 + 눈썹 마커 정확히 세기

### 🟢 LOW (30점)

4. Question 1-4: 영상 확인으로 검증
