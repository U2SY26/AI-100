### 문제 1: 조리법별 메뉴 분석 (10점)

#### 문제 설명
1월 13일 주간(1/13-1/17) 중식의 **한식A, 한식B, 팝업A, 팝업B, 양식** 코너에서 제공된 반찬들 중, 반찬명이 정확히 **조림, 볶음, 무침, 구이**로 끝나는 개수를 세어 내림차순으로 정렬합니다.

#### 핵심 포인트
- ✅ **정확히** "조림", "볶음", "무침", "구이"로 **끝나야** 함
- ✅ 샐러드바 제외 (5개 코너만)
- ✅ 주간 = 월-금 5일치
- ❌ "양념구이" → X (구이로 끝나지만 "양념"이 붙음)
- ❌ "쌈" → X (조리법 아님)

#### 예시
```python
# ✅ 카운트 대상
"두부조림"      → 조림 +1
"시금치무침"    → 무침 +1
"제육볶음"      → 볶음 +1
"고등어구이"    → 구이 +1

# ❌ 카운트 제외
"상추양배추쌈*쌈장"  → 조리법 아님
"알타리김치"         → 조리법 아님
"짜글이"             → 조리법 아님
"양념게장"           → "조림"이 아님
```

#### 풀이 코드
```python
def solve_question_1(df):
    # 1/13-1/17 주간 중식 데이터 필터링
    target_data = df[
        (df['date'] >= '2025-01-13') &
        (df['date'] <= '2025-01-17') &
        (df['meal_type'] == '중식') &
        (df['corner'].isin(['한식A', '한식B', '팝업A', '팝업B', '양식']))
    ]

    # 조리법별 카운트
    cooking_methods = ["조림", "볶음", "무침", "구이"]
    cooking_counts = {method: 0 for method in cooking_methods}

    for _, row in target_data.iterrows():
        for dish in row['side_dishes']:
            for method in cooking_methods:
                if dish.endswith(method):  # 정확히 끝나야 함
                    cooking_counts[method] += 1

    # 내림차순 정렬
    sorted_methods = sorted(
        cooking_counts.items(),
        key=lambda x: x[1],
        reverse=True
    )

    return ' > '.join([method for method, count in sorted_methods])
```

#### 답안 형식
```
볶음 > 무침 > 조림 > 구이
```

### 문제 2: 1월 칼로리 순위 분석 (15점)

#### 문제 설명
1월 전체 중식의 **한식A, 한식B, 양식, 팝업A, 팝업B** 코너의 평균 칼로리를 각각 계산하고 내림차순으로 정렬합니다.

#### 핵심 포인트
- ✅ 1월 전체 (1/6 주간 + 1/13 주간 + 1/20 주간)
- ✅ 중식만 (석식 제외)
- ✅ 5개 코너만 (샐러드바, TAKE OUT 제외)
- ✅ 평균 계산 필요

#### 데이터 수집 전략
```
1월 전체 영업일: 약 20일
각 코너별: 약 20개 데이터 포인트
→ 코너별 평균 칼로리 계산
```

#### 풀이 코드
```python
def solve_question_2(df):
    # 1월 중식 데이터
    jan_lunch = df[
        (df['date'].str.startswith('2025-01')) &
        (df['meal_type'] == '중식') &
        (df['corner'].isin(['한식A', '한식B', '양식', '팝업A', '팝업B']))
    ]

    # 코너별 평균 칼로리
    avg_calories = jan_lunch.groupby('corner')['calories'].mean().round(2)

    # 내림차순 정렬
    sorted_corners = avg_calories.sort_values(ascending=False)

    return ' > '.join(sorted_corners.index.tolist())
```

#### 예상 결과
```
양식 > 한식A > 팝업B > 한식B > 팝업A
```

### 문제 3: 지역 특색 메뉴 (15점)

#### 문제 설명
1-2월의 모든 범위(중식, 중식 TAKE OUT, 석식, 석식 TAKE OUT)의 **메뉴명**에 포함된 지역명(국가/도시/지명)을 추출하고, **2회 이상 등장한 지역**을 모두 선택합니다.

#### 핵심 포인트
- ✅ 메뉴명만 확인 (반찬명 제외)
- ✅ 모든 식사 구분 포함
- ✅ 1월 + 2월 전체
- ✅ 2회 이상 (1회는 제외)

#### 지역명 예시
```python
regions = [
    "안동",      # 안동찜닭
    "전주",      # 전주비빔밥
    "베트남",    # 베트남쌀국수
    "나가사키",  # 나가사키짬뽕
    "태국",      # 태국볶음밥
    "춘천",      # 춘천닭갈비
    "제주",      # 제주흑돼지
    "부산",      # 부산어묵
    "일본",      # 일본식카레
    "중국"       # 중국식짜장면
]
```

#### 풀이 코드
```python
def solve_question_3(df):
    regions = ["안동", "전주", "베트남", "나가사키", "태국",
               "춘천", "제주", "부산", "일본", "중국"]

    region_counts = {region: 0 for region in regions}

    # 모든 메뉴명에서 지역명 검색
    for _, row in df.iterrows():
        menu_name = row['menu_name']
        for region in regions:
            if region in menu_name:
                region_counts[region] += 1

    # 2회 이상 등장한 지역
    result = [
        region for region, count in region_counts.items()
        if count >= 2
    ]

    return sorted(result)  # 가나다순 정렬
```

### 문제 4: 메뉴별 칼로리 비교 (10점)

#### 문제 설명
1-2월에서 다음 메뉴들의 칼로리를 찾아 내림차순으로 정렬합니다.

**대상 메뉴** (가나다순):
1. 덴가스떡볶이
2. 돈코츠라멘
3. 마라탕면
4. 수제남산왕돈까스
5. 탄탄면

#### 핵심 포인트
- ✅ 메뉴명 정확히 일치해야 함
- ✅ 1-2월 전체 범위
- ✅ 칼로리 값 추출

#### 풀이 코드
```python
def solve_question_4(df):
    target_menus = ["덴가스떡볶이", "돈코츠라멘", "마라탕면",
                    "수제남산왕돈까스", "탄탄면"]

    menu_calories = {}

    for menu in target_menus:
        # 부분 문자열 매칭
        matching = df[df['menu_name'].str.contains(menu, na=False)]
        if not matching.empty:
            menu_calories[menu] = matching.iloc[0]['calories']

    # 내림차순 정렬
    sorted_menus = sorted(
        menu_calories.items(),
        key=lambda x: x[1],
        reverse=True
    )

    return ' > '.join([menu for menu, cal in sorted_menus])
```

### 문제 5: 2월 한 달 식단 최적화 (40점)

#### 문제 설명
2월 한 달간 칼로리 기준으로 최적 조합을 찾습니다.

**조건**:
1. **월-목요일**: 중식 + 석식 합계가 **1,550kcal에 가장 근접**한 코너 조합
2. **금요일**: 가장 칼로리가 낮은 중식 코너

**분석 대상 코너**:
- 중식: 한식A, 한식B, 양식, 팝업A, 팝업B
- 중식 TAKE OUT: 샐러드, 비건, 라이스&누들, 버거&델리
- 석식: 한식B, 샐러드바
- 석식 TAKE OUT: 샐러드, 버거&델리

#### 핵심 포인트
- ✅ 2월 평일만 (약 20일)
- ✅ 금요일은 석식 없음 (중식만)
- ✅ 1550kcal에 **가장 근접** (딱 1550이 아님)
- ✅ 날짜당 2점 (20일 × 2점 = 40점)

#### 2월 날짜 계산
```python
# 2025년 2월 평일
dates = [
    "2025-02-03", "2025-02-04", "2025-02-05", "2025-02-06", "2025-02-07",  # 월-금
    "2025-02-10", "2025-02-11", "2025-02-12", "2025-02-13", "2025-02-14",  # 월-금
    "2025-02-17", "2025-02-18", "2025-02-19", "2025-02-20", "2025-02-21",  # 월-금
    "2025-02-24", "2025-02-25", "2025-02-26", "2025-02-27", "2025-02-28",  # 월-금
]
# 총 20일
```

#### 풀이 알고리즘
```python
def solve_question_5(df):
    feb_data = df[df['date'].str.startswith('2025-02')]
    result = []

    dates = sorted(feb_data['date'].unique())

    for date in dates:
        day_data = feb_data[feb_data['date'] == date]
        weekday = datetime.strptime(date, '%Y-%m-%d').weekday()

        if weekday == 4:  # 금요일 (0=월요일)
            # 중식만, 가장 낮은 칼로리
            lunch_data = day_data[day_data['meal_type'].str.contains('중식')]
            if not lunch_data.empty:
                min_row = lunch_data.loc[lunch_data['calories'].idxmin()]
                result.append({
                    "id": date,
                    "lunch": min_row['corner']
                })
        else:
            # 월-목: 중식+석식 = 1550kcal에 근접
            lunch_data = day_data[day_data['meal_type'].str.contains('중식')]
            dinner_data = day_data[day_data['meal_type'].str.contains('석식')]

            best_diff = float('inf')
            best_combo = None

            # 모든 조합 시도
            for _, lunch in lunch_data.iterrows():
                for _, dinner in dinner_data.iterrows():
                    total_cal = lunch['calories'] + dinner['calories']
                    diff = abs(total_cal - 1550)

                    if diff < best_diff:
                        best_diff = diff
                        best_combo = {
                            "id": date,
                            "lunch": lunch['corner'],
                            "dinner": dinner['corner']
                        }

            if best_combo:
                result.append(best_combo)

    return result
```

### ❌ 실수 1: 날짜 범위 오류
```python
# 잘못된 예
df[df['date'] == '2025-01-13']  # 1일치만

# 올바른 예
df[(df['date'] >= '2025-01-13') & (df['date'] <= '2025-01-17')]
```

### ❌ 실수 2: 코너 누락
```python
# 잘못된 예 - 샐러드바 포함

# 올바른 예
corners = ['한식A', '한식B', '팝업A', '팝업B', '양식']  # 샐러드바 제외
```

if dish.endswith('구이'):  # 정확히 끝나는 것만

## 도구 사용법

### Streamlit 앱 실행
```bash
# 1. 앱 실행
streamlit run menu_data_entry.py

# 2. 브라우저 자동 열림 (http://localhost:8501)
```

### 데이터 입력
1. **데이터 입력 탭** 선택
2. 날짜, 식사 구분, 코너 선택
3. 메뉴명, 칼로리 입력
4. 반찬 입력 (한 줄에 하나씩)
5. "메뉴 추가" 클릭

### 문제 풀이
1. **문제 풀이 탭** 선택
2. 원하는 문제의 "풀이" 버튼 클릭
3. 자동 계산된 답 확인
4. 답 복사하여 제출

### 데이터 저장/불러오기
```bash
# 데이터 관리 탭에서
1. "JSON 저장" 클릭 → menu_data.json 생성
2. 다음 세션에서 "파일 업로드"로 불러오기
```
